# AI Music Mastery - Web Interface

A Gradio-based web interface for the AI Music Mastery System.

## Features

- **Vocal Upload**: Support for WAV and MP3 vocal tracks.
- **Genre Selection**: Choose from Pop, Rock, Jazz, Electronic, Hip-Hop, Classical, Folk, or R&B.
- **AI Backend Selection**: Support for Synthetic, Mubert API, and MusicGen.
- **Advanced Mixing**: Adjustable vocal and instrumental gain.
- **Metadata Display**: View key, tempo, mood, and copyright info of the generated track.

## Dependencies

- `gradio`
- `ai_music_mastery` (Expected to be in the python path or same directory)

## Usage

```bash
python music_mastery_ui.py
```

Open your browser at `http://localhost:7860`.
